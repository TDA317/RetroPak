Credits & References ×

Acknowledgements

This editor is dedicated to the retro-gaming and modding communities. Special thanks to id Software (Quake engine series) and Valve Corporation (Half-Life/GoldSrc engine) for making their formats open and accessible. Coded using Gemini 3.5 via Antigravity, with Quake 3 map support added using GLM 5.2 (Z.AI).

Core References & Inspiration

  • TrenchBroom: The industry-standard level editor. Inspired our noclip and fly-through 3D camera mouse/keyboard control layouts. GitHub
  • PakFu: A robust archive editor for idTech games. Attributed as reference for PK3 zip inflation, game profiles, and archive support matrix design. GitHub
  • Q1Tools: Client-side browser utilities for Quake assets. Guided patterns for binary model and texture decoders. GitHub
  • Sutherland-Hodgman Algorithm: Used as the base math code for clipping polygons against the camera view plane in WebGL texture mapping.

Reference Implementations

  • Brandon Jones (toji): Original WebGL Quake 3 BSP renderer. The foundational reference for shader parsing, Bezier tessellation, and multi-stage rendering. GitHub
  • sairuk: Fork/continuation of toji's work with lightmap overbright, vertex color brightening, and multi-extension texture probing. GitHub
  • passiomatic: Elm-based Q3 renderer with hand-tuned per-stage GLSL, depth-range partitioning for sky, and explicit NPOT texture handling. GitHub

Official Source Code

  • id Software (Quake 1): Original Quake engine source code. Essential for understanding original software rendering pipeline, BSP structure, and texture definitions. GitHub
  • id Software (Quake 2): Quake 2 engine source code. Vital for parsing IBSP version 38 maps, WAL texture formats, and GL rendering pathways. GitHub
  • id Software (Quake 3): Quake 3 Arena engine source code. Critical for understanding overbright bits, GL state management, depth testing rules, and fog volume handling. GitHub
  • Valve Software: Half-Life 1 SDK. Reference for GoldSrc engine structures, Half-Life Model (MDL) StudioModel specs, Sprites, and WAD3 format. GitHub

Technical Documentation

  • Quake 1 BSP Format Specification: Detailed breakdown of the Quake 1 BSP structures, faces, leaf nodes, and lightmaps.
  • Quake 2 BSP Format Reference (Mr. Alligator): Documentation on Quake 2 IBSP (version 38) lump offsets and structures.
  • GoldSrc BSP Structures (Valve): Header file detailing the Half-Life BSP v30 format limits and struct layouts.
  • Quake 3 BSP Format Reference (Mr. Alligator): Documentation on the Quake 3 IBSP (version 46) structure layout.
  • Quake 3 Shader Manual (PDF): Stanford-hosted copy of the official Q3 shader manual.
  • Q3A Shader Manual (icculus): Hosted copy with stage directives reference.
  • q3map2 Shader Manual: Detailed blendFunc, rgbGen, and tcMod stage directives reference.

Model & Texture Specifications

  • StudioModel (Half-Life MDL): Decoded using the structure layout derived from Valve's official engine SDK source header `studio.h`. SDK Reference
  • MD2 Model Format: Quake 2's mesh format, parsed using the classic MD2 format specification. Engine Code Reference
  • MD3 Model Format: Quake 3 Arena mesh format with morph targets, shaders, and tag attachment pivots. Engine Code Reference
  • MD5 Skeletal Models (Doom 3 / Quake Remaster): skeletal animation specification (`md5mesh` / `md5anim`) for bones, joints, weights, and keyframes. Reference: David Henry. Specification
  • InterQuake Model (IQM): Modern skeletal animation model format. Reference: Lee Salzman (lsalzman) and Wouter van Oortmerssen. Specification / SDK Loader Source
  • WAL Texture Spec: Mipmapped WAL format, referenced from id Software's Quake 2 graphics pipeline. Header Reference

Detailed Formats & Specifications Included

  • Archives: PACK/PAK (Quake 1/2), PK3 zip-inflated mod archives (Quake 3), WAD2/WAD3 (Quake/Half-Life).
  • 3D Levels (BSP): Quake 1 (v29), Quake 2 (v38), Half-Life (v30), Quake 3 Arena (IBSP v46), BSPX extensions lump directory table parsing, Bezier patch curve generation, and multi-stage shader parser integration.
  • 3D Models: Quake 1 MDL, Half-Life MDL (IDST v10), Quake 2 MD2, Quake 3 MD3, IQM (InterQuake Model), Doom 3 MD5Mesh/MD5Anim skeletal animation files.
  • 2D Graphics & Audio: PCX, TGA, WAL, Half-Life Sprites (v2), WAV audio metadata header parsing.
